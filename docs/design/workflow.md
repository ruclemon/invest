# 研究与报告流程

本页保存研究报告设计，供人工研究或以后实现时参考。目前没有自动流水线。报告提供判断和证据，不输出仓位、调仓计划或交易指令。

## 从问题到复盘

```mermaid
flowchart LR
    A[提出研究问题] --> B[收集事实与文章]
    B --> C[清洗 去重 分类]
    C --> D[资产映射与证据整理]
    D --> E[形成不同期限的判断]
    E --> F[解释策略逻辑与风险]
    F --> G[撰写报告]
    G --> H[核对变化与复盘]
    H --> A
```

1. 明确研究对象、时间窗口和要验证的错配：驱动、利润、共识或价格。
2. 收集可追溯的信息，记录发布时间、来源、市场和数据覆盖。缺失项单独列出。
3. 清洗无关页面内容，识别转载和跨批次重复，区分事实新闻与作者观点。
4. 逐资产提炼立场、依据和反证，观察来源集中度，不按文章数量直接投票。
5. 分别形成短期和中期判断，解释变化来自价格、基本面、观点流还是信息缺失。
6. 分析方向、配对、价差、Carry 或对冲的逻辑，说明各条腿的角色和失效条件，不给出配置权重。
7. 先整理结构化结论和证据，再组织可读文字。LLM 只使用明确提供的材料。
8. 复盘实际变化、假设兑现和错误来源，区分判断错误、时机错误与执行错误。

## 新闻处理与选择

RSS、人工资料和未来可用的文章获取方式都是输入。微信公众号旧服务已停用；仅保留订阅需求，不保留登录与抓取流程。

去重分为文章身份去重和主题聚类。相同文章转载不算多份独立证据；同主题的不同观点仍应保留差异。新闻与观点分类服务于不同用途：新闻用于事件和事实，观点用于作者立场。旧设计曾在来源连续三篇判为新闻后长期标记整源，该规则可能误判后续观点文，仅留作历史经验，不设为新规则。

采集候选窗口和报告展示窗口应分开。旧草案采用 48 小时候选、36 小时展示，并防止前一日展示内容再次占榜；这是旧参数参考，不是当前时效承诺。样本不足时明确低覆盖，不用过期内容伪装成新信息。

筛选考虑相关性、时效、内容完整性、来源质量和主题覆盖。篇幅、噪声及来源集中度可以辅助检查，但短文不必然低质，转载数量也不代表可信度。宏观榜与个股榜的配额应另行定义。

## 报告模板

### 资产观点

| 字段 | 内容 |
|---|---|
| 对象与期限 | 资产类别、观察标的、分析时点与适用窗口；旧参考为 7 天 / 90 天 |
| 当前判断 | 偏多、偏空、中性或证据不足；不同期限可以不同 |
| 核心驱动 | 最重要的基本面、流动性、价格状态或事件变化 |
| 支持与反方证据 | 可追溯资料、分歧、来源覆盖及缺项 |
| 相比上次变化 | 结论是否变化、由什么新证据导致 |
| 催化与失效条件 | 要观察什么，发生什么时应撤回判断 |
| 可选目标 | 只有存在可靠锚点时提供价格区间，说明估算方法 |

### 策略表达

说明策略类型、各条腿的研究对象与方向、收益来源、风险暴露和失效条件。把方向收益、Carry 和价差收敛分开，不用“对冲”一词省略风险解释。不生成仓位权重、调仓数量或下单计划。

报告正文保留结论、变化、理由、用法和风险；明细、口径与缺失信息放在数据说明。观点生成失败或关键证据缺失时停止正式结论，预览材料应明确标为非正式。旧草案中的静默 fallback、置信度默认值和旧产物替代，不作为新流程。

### 解读纪律

- 区分事实、指标、推断和猜测。
- 长期方法笔记不属于当天市场证据。
- 不能根据没有提供的价格、新闻或模型结果编造解释。
- 明确证据不足与多空分歧的区别。
- 分别解释短期交易立场和长期结构性看法。
- 复盘不只记录盈亏，也记录条件是否发生、判断为何改变。

## ETF、日历和预测市场

ETF 以资产类别或“市场 × 行业”分组观察，单只 ETF 提供底层映射。区分发行中、待上市、已上市；区分原始范围与正式纳入范围。AUM、份额、币种和覆盖率一起说明，AUM 增加不能直接解释为资金流入。移除事件要排除源缺失；美股与 A 股行业观察不混为一个总量。

日历区分公告、执行、生效日期，以及确定日期和估计窗口。精度不足只能显示月度窗口；官方时间表与人工修正冲突时核对来源，不静默覆盖。旧文档对优先级存在分歧，见 [数据定义](data_definitions.md)。

预测市场关注宏观、央行、监管、地缘、商品和产业政策事件。旧方案按成交量和价格变化各 0.5 排名，使用主题配额避免单一事件占满榜单，具体阈值留在参数参考。概率与概率变化不是标的收益预测；解释“市场在交易什么”，同时保留事件结算条件和流动性边界。
