# 研究想法

本页保留尚未排期的研究问题。已确认工作见 [TODO](TODO.md)，不继承旧项目的工程任务编号或完成度。

## 投资与策略研究

- [ ] 把驱动变化、利润传导、共识扩散、跨市场 lead-lag、拥挤度与估值错配分别表达，研究其增量信息。
- [ ] 研究同资产价差、跨资产配对，以及怎样把方向判断转化为 Carry、价差或对冲结构。
- [ ] 研究 Polymarket 概率异动是否提供新的事件信息，区分结算规则、流动性与真实信息变化。
- [ ] 研究 Seeking Alpha 作者观点、评级修正及市场反应；不预设能取得所需数据。
- [ ] 研究 Chasing Beta：按市场、行业和风格暴露管理风险预算，而不是只追求单标排名。
- [ ] 将人工判断作为单独的研究输入，保留理由、期限和失效条件，避免与模型分数混为一谈。

## 数据与因子研究

- [ ] 基本面 PE / PB / ROE、期限结构、期货及永续 OI、成交活跃度与流动性深度。
- [ ] ETF 新发行、规模、份额与行业集中度能否辅助观察风险偏好。先分清价格变化与真实申赎。
- [ ] 搜索热度能否在价格和新闻之外提供信息；比较关键词、时间尺度和覆盖稳定性。
- [ ] 作者权重和集中度约束是否有效。人工提高作者权重属于假设，不等于历史预测能力。
- [ ] 评价因子和策略时区分方向、强度、风险与交易成本，不把分布校准当作有效性验证。

## 信息质量与报告

- [ ] 区分高可信研究源、主流声音源和噪音源。主流声音可能反映拥挤和波动，不自动视为正确观点或反向指标。
- [ ] 研究宏观与个股榜单的分工、配额和去重；低样本时说明覆盖不足。
- [ ] 事件排序同时考虑临近程度和持续影响，避免仅靠固定日期窗口遗漏重要事件。
- [ ] 报告增加观点变化原因、反方证据、催化因素和复盘反馈。
- [ ] 来源扩展资料：Substack 作者如 Lyn Alden、Eric Peters，及未确认稳定入口的加密媒体；仅保留研究记录，不安排自动接入。
