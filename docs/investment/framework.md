# 分析框架

> 来源：旧项目 `docs/notes/framework.md`，迁移日期 2026-11-16。正文保留原有观点；具体案例与判断属于历史笔记，不表示当前建议或已验证收益。

## 资产价格三要素

资产价格由 3 个重要因素驱动：**基本面**、**估值**、**流动性**。

- 基本面是真实世界的供需结构/盈利能力/利率环境。
- 估值由预期/风险偏好/情绪/叙事决定。
- 流动性是资金约束，体现为宏观利率+信贷扩张+杠杆条件。

三者共同作用，但主导权随宏观环境与制度变化动态切换。

## 主导因子与定价框架

在主导因子未发生结构性变化时，价格围绕既有定价框架波动，呈现均值回归特征，适用于反转因子。

当主导因子发生切换时，定价框架重构，价格进入单边趋势，对应估值与基本面的同向变化，即戴维斯双击或戴维斯双杀，适用于趋势因子。

主导因子稳定时做反转，主导因子切换时做趋势。

**不切换就回归，一切换就重定价。**




## 主导变量判断

先判断市场在交易什么，再决定用什么框架；先定主导变量，再定研究方法。

不是任何时候都该先看宏观，有些阶段通胀、失业率、利率只是背景，不是主角。

当市场主要由资金拥挤推动时，价格的短期变化往往先由持仓、成交和波动率解释，而不是由基本面解释。

当市场主要由地缘事件推动时，价格的节奏更多取决于事件预期、情绪传导和风险重定价，而不是常规数据发布。

所以分析的第一步，不是问“资产贵不贵”，而是先问“市场眼下最在乎什么”。

如果主导变量判断错了，后面的研究越努力，越可能只是用错框架解释错行情。

持仓研究更偏向解决短期机会，因为资金流进出快，价格和波动率的反馈也快。

地缘研究更偏向解决中期机会，因为事件可以提前规划，但真正定价往往分阶段展开。

没有先手优势，就很难在地缘波动里赚钱；而先手优势通常来自提前做持仓跟踪和事件预案。

交易上最重要的不是“什么都懂”，而是先识别这段行情究竟是资金流主导，还是地缘主导。

## 基本面分析

基本面分析的目标，是判断未来现金流、折现水平以及不确定性。

- 商业模式决定收入是否具备可重复性与可扩展性。
- 竞争优势决定利润能否长期维持。
- 行业结构决定利润是被竞争挤压还是被有效保护。
- 单位经济决定增长是在放大利润还是放大亏损。
- 资本分配决定现金流是被复利放大还是被低效消耗。
- 周期位置决定盈利所处顺逆风阶段——你是在赚成长的钱还是周期的钱。

结合传统指标（PE/PB、ROE、增长、供需），本质是在用估值锚定当下、用盈利能力验证质量、用增长与供需刻画弹性，从而识别当前价格与未来现金流之间的预期差。

寻找那些“驱动变量已经变化，但利润尚未被定价”的标的，是最稳定的一类alpha来源；本质是利用信息传导与市场反应之间的时间差，在变量、利润与价格三者之间寻找错配。

## 资金面分析

价格能不能涨，不取决于逻辑，而取决于有没有持续买盘；资金面就是在找"谁必须买、谁被迫卖"。

- 有没有稳定的买盘来源（ETF / 公募 / 外资）。
- 有没有必须买的资金（调仓 / squeeze）。
- 有没有被迫卖的资金（赎回 / 强平）。
- 价格由持续买盘推动，加速来自必须买，而剧烈波动和拐点往往来自被迫买（如交割、保证金上调、强平）。
- 期货：交割不创造趋势，但会制造波动和错价；保证金上调 = 系统性流动性收紧。

季度末盯住被动资金再平衡。很多异动不是新信息，而是机械调仓。机械调仓冲出来的价格，往往更容易反转。

## 技术指标的本质

- 均线不是线，是群体成本线 + 情绪分界线。
- 支撑位 = 潜在买盘堆积区，历史上买盘密集 + 未完成需求的位置。
- 阻力位 = 潜在卖盘堆积区，历史上卖压密集 + 解套盘释放的位置。
- 它们都是订单簿的历史残影。
- 价格的阻力和支撑，本质来自成本分布，即市场所有人的买入成本分布图。
- 波动率 = 价格波动幅度的度量；波动率决定空间，而不是方向。

## 预期与博弈

- 买预期卖事实：市场会因预期和情绪过度定价，价格可以长期偏离价值；但当预期被充分交易并兑现时，边际力量消失，价格往往反转。
- 当所有人都相信某个故事，价格已经提前上涨，而利好落地不再推动价格时，预期通常已经被透支。
- 先信的人赚钱，后信的人买单；先信资本卖给后信的人。
- 先信不是最早知道，而是在叙事尚未形成共识、但具备扩散条件且已有早期资金验证时入场。
- 信息本身不值钱，信息的解读才值钱。
- 共识不是机会，分歧才是机会；但分歧必须最终走向共识才会赚钱。
- 共识生命周期模型：早期 → 强化 → 拥挤 → 崩塌。
- 关键不是判断是不是共识，而是共识在形成、强化，还是在透支。
- 非共识阶段赚预期扩散的钱，共识阶段赚资金接力的钱。
- 当共识转为拥挤且边际资金消失时，价格反转。
- 重仓才有认知，轻仓只是观点。
- 没有垃圾的产品，只有垃圾的价格。

### 短期定价是共识投票

市场短期从来都不是称重机，短期它就是投票器。
价格涨不涨，不取决于这件事是不是“客观利好”，而取决于市场有没有形成一致预期，进一步说，取决于有没有形成可交易的共识。

比如，你认为 A 公司有利好，但别人不这么看。
那这只是你的判断，不是市场的判断。
没有形成合力，价格就很难动。

再进一步，假设你和张三都觉得 A 公司有利好。
但问题在于，你不知道他也这么想，他也不知道你这么想。
这说明什么？说明预期是分散的，共识没有被确认。
没有被确认的共识，本质上就不是共识。
它最多只是“零散的正确”，还不足以变成集体交易行为，所以价格反应也不会太大。

真正能把价格推起来的，是更强的一层：
你觉得有利好，张三也觉得有利好，
而且你知道他看到了，他也知道你看到了。
这时候市场才从“各自判断”走向“共同定价”。
一旦这种共识被彼此确认，买盘才会集中，价格才会出现明显抬升。

所以很多人做交易，问题不在于信息对不对，
而在于他只看到了“事件本身”，没有看到“市场共识走到了哪一步”。
短期定价，定的不是事实本身，定的是事实被多少人相信，以及大家是否知道彼此都在相信。

### 矛盾逻辑与更高层变量

同一个市场，允许矛盾逻辑同时存在。
如果 A 和 B 正在不计成本打价格战，但两家公司的股价都在上涨，不必急着判断市场错了。
静态看，A 和 B 竞争会损害利润，最后似乎只能有一个赢家；但动态看，A 的资金在押 A 赢，B 的资金在押 B 赢，还有一批资金干脆同时买 A 和 B，押注整个赛道扩张。

这类盘面不是在交易“谁一定赢”，而是在交易“这个行业足够大、胜负还没分、波动足够高”。
所以 A 和 B可以逻辑矛盾，但价格同涨；
就像哑铃策略，同时买确定性龙头和高弹性挑战者；也像期权双买，不判断方向，只押波动放大。

看到这种市场，不需要强行把所有现象解释成一个统一逻辑。
先承认盘面，再分析原因；先跟随趋势，再等待胜负。
放下执念，不要求一切东西都有一个统一逻辑。
市场短期不是逻辑考试，而是资金投票。

看到矛盾资产同时上涨，不要先问“谁错了”，要先问“它们是不是在交易同一个更高层变量”。

公司竞争型：
电动车价格战：特斯拉 vs 比亚迪 表面是价格战，互相压利润；更高层变量是电动车渗透率提升。
AI 算力竞争：英伟达 vs AMD 表面是 GPU 份额竞争；更高层变量是 AI 算力需求爆发。
云计算竞争：AWS vs Azure 表面是云厂商争夺企业客户；更高层变量是企业上云、AI 云、算力基础设施扩张。
AI 搜索入口竞争：Google vs OpenAI / Microsoft 表面是搜索入口被颠覆；更高层变量是 AI 成为下一代信息入口。

大类资产型：
碳酸锂和油煤同时上涨 表面上新能源和旧能源互相替代；更高层变量是能源紧张、供给不足。
黄金和美元同时上涨 表面上美元强会压制黄金；更高层变量是全球避险。美元是流动性避险，黄金是信用避险。
股票和债券同时上涨 表面上股票代表风险偏好，债券代表避险；更高层变量是降息预期。股票涨估值，债券涨价格。
黄金和科技股同时上涨 表面上黄金是避险资产，科技股是风险资产；更高层变量是实际利率下行。

## 市场永远是对的 vs 市场有时候是错的

这两句话都对，但说的是两个不同维度：一个讲短期结果，一个讲长期价值。
从短期结果看，市场永远是对的，因为价格已经成交，盈亏已经发生。
你可以觉得市场荒谬，但只要价格继续朝你不利的方向走，交易层面就是你错了。
所以做短期交易，第一原则不是证明自己正确，而是尊重价格、控制风险、保住仓位。

从长期价值看，市场有时候是错的，因为价格会被情绪、流动性、杠杆和叙事反复扭曲。
但长期里，价格最终仍会向现金流、资产质量、竞争优势和回报率这些基本面回归。
也正因为市场会犯错，价值投资、逆向投资和折价投资才有存在空间。

投资中最常见的错误，就是用长期价值给短期亏损找借口，或者被短期波动逼着放弃长期判断。
交易时要记住：短期里市场是裁判；投资时要记住：长期里价值是裁判。
结论：短期尊重市场，长期锚定价值，不要把两个时间尺度混为一谈。

### 市场对错-美伊停火案例

以 2026.4.7 美伊停火引发市场反弹 为例，短期里这根大阳线，就是市场对“极端风险暂时解除”的直接定价。
从这个角度看，市场永远是对的，因为价格已经上涨，资金已经回流，结果已经发生。

如果你在恐慌中抄底、加仓或继续持有，那么这波上涨，就是市场对你承担风险的奖励。
如果你提前减仓、清仓，结果错过反弹，那也只能愿赌服输，因为市场不会为个人看法停下来。

但从更长期看，市场有时候是错的，因为停火未必稳固，后续摩擦、违约甚至反复升级，都会让当天的乐观定价被重新修正。
结论：短期要尊重市场对边际变化的选择，长期要保留对终局价值的判断，不要把当天的暴涨误当成最终答案。

## 信息与价格传播理论：Lead–Lag

不同资产由于交易时段、投资者结构、信息处理速度不同，对同一信息的价格反应往往并不同步，因此会形成 lead–lag（领先—滞后）关系。
信息与市场共识并不是一次性完成定价，而是在不同市场、不同资产之间逐步传播，价格也随之分阶段反映。

这种 lead–lag 关系通常来自以下几个方面：

1. 时间错位
先开盘的市场往往先对信息作出反应，后开盘的市场再跟随调整。

2. 信息处理差异
不同市场对信息的敏感度不同。
有的市场更“敏感”，更早反映预期变化；有的市场更“迟钝”，需要更长时间才能完成定价。
例如，美股常常是全球风险偏好的核心定价中心，而大宗商品往往更早反映宏观预期变化。

3. 共识传播（Narrative Diffusion）
信息的传播路径通常是：信息出现 → 少数人先理解 → 更多人形成共识 → 资金开始配置 → 价格完成重估。
也就是说，价格变化往往不仅是对事实的反应，更是对“市场共识扩散速度”的反应。

常见的传导路径包括：

美股先跌，港股与日股随后下跌：体现的是时间错位与风险情绪传导。
原油上涨 → 利率上升 → 黄金下跌：体现的是通胀预期与实际利率传导。
利率上升 → 科技股下跌：体现的是估值折现传导。
美元走强 → 新兴市场下跌：体现的是资金流动与汇率压力传导。
半导体上涨 → 产业链个股重定价：体现的是产业链景气度传导。
政策宽松 → 多资产上涨：体现的是流动性扩散。
商品价格上涨领先股票盈利改善：体现的是供需变化领先利润表。
小盘股领先大盘股见顶：体现的是风险偏好变化往往先在高弹性资产中出现。

一句话总结：
市场并不是同时定价，而是沿着“信息 → 共识 → 资金 → 价格”的路径分层传播；谁更早处理信息，谁就更可能成为领先指标。

## 产业链利润分配

在供给受限或需求爆发阶段，上游价格上涨快于下游利润传导，面粉可能阶段性贵过面包。

当供给恢复或需求转弱时，利润从上游回流至下游，价格关系恢复。

价格不反映成本结构，而反映利润分配与预期变化。

## 规则市场中的争议结算

对于有明确结算期限或明确交割规则的市场，临近关键时点时，交易的往往不只是事实本身，而是事实最终会在规则框架下如何被解释、结算或交割。

这类市场的价格，反映的不只是事件概率或资产价值，还反映规则解释权、交割机制、流动性约束、媒体口径和最终共识预期。

Polymarket 这次“美伊 4 月 7 日前停火”是规则解释型案例，2020 年 WTI 负油价则是交割机制型案例。

两者表面上看分别在交易“是否停火”和“原油价格”，实质上都在交易规则边界下的最终结果。

只要市场在关键时点高度依赖 clarification、结算解释、交割能力、仓储约束或被动资金行为，就要默认存在结构性风险。

大资金在临近结算或交割时，影响的往往不只是价格，还可能影响叙事、预期、流动性和最终结果。

一句话：这类市场里，真正要防的不是看错方向，而是方向看对了，却输在规则、交割和结算机制上。

## 跨境价差

可套利的价差终将收敛，不可套利的价差只会重定价。

上海金与伦敦金在跨境流动顺畅时趋于收敛，在资本管制或流动受限时可能长期存在溢价或折价。
