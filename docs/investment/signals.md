# 因子、观点与组合

本文提炼旧项目设计。公式、参数及策略形态是研究参考，不代表已验证的超额收益或正在运行的系统。精确旧参数见 [研究参数参考](../../resources/legacy/research_parameters.json)。

## 研究问题先于分数

核心研究问题是驱动、利润、共识与价格之间是否出现错配，以及错配处于哪个传播阶段。通用方向分不能替代这些判断。

| 研究维度 | 要回答的问题 |
|---|---|
| 驱动变化 | 供需、政策、流动性或产业变量发生了什么变化？ |
| 利润传导 | 变化先影响谁的收入、成本和利润？ |
| 信息传播 | 哪个市场先定价，哪个标的仍滞后？ |
| 共识与拥挤 | 观点刚形成、正在扩散，还是已被价格透支？ |
| 估值与结构 | 相对价值、期限结构和交易工具是否提供更好的表达？ |

旧项目已能把价格特征和文章观点相加，但上述维度尚未充分表达。新研究不能把“分数更高”直接等同于“机会更好”。

## 价格、波动与热度

### 趋势与反转

趋势参考短长周期均线、波动尺度和历史分布。旧配置的短长 EMA 与波动窗口为 5 / 60，另有分位校准参数。这些参数仅记录旧设定，完整趋势计算口径未在本次迁移中重新验证。

反转设计：

```text
z_adj = z - center_weight * b - std_weight * shift
q_t = rolling_quantile(abs(z_adj), 0.98, window=1年)
scale_raw_t = atanh(0.98) / max(q_t, eps)
scale_t = EMA(scale_raw_t, span=20)
reverse_0 = -tanh(scale_t * z_adj)
```

`z` 表示价格相对长期基准的标准化偏离；`b` 和 `shift` 分别用于局部中心和波动缓冲。自适应缩放试图让不同资产的尾部强度可比，并非收益校准。样本长度、异常点及分布变化会影响结果；短样本应明确不足，不能把旧固定参数回退当作已验证结果。

### 波动率

```text
r_t = ln(close_t / close_(t-1))
rv_20 = std(r_(t-19:t)) * sqrt(年交易日数)
vol_pct_1y = 当前 rv_20 在过去一年中的经验分位数
```

旧设计同时观察 10 日和 20 日实现波动率；状态阈值为 0.2 / 0.8。年化日数要与市场交易日历一致，不能把股票的 252 日直接套用所有市场。波动率描述风险状态，不直接表示看多或看空。

### 搜索与交易热度

搜索热度先把每个关键词的序列转换成自身过去两年的历史分位数，再对同一资产的关键词等权平均。旧方案使用周频序列，日频展示时延续最近已知值；不平均不同关键词的原始搜索指数。关键词覆盖变化需要同时说明。

交易热度衡量同一资产相对自身历史的活跃程度。旧草案保留以下候选量：

```text
vol_ratio = clip(volume / rolling_mean(volume, 20), 0, 5)
vol_trend = tanh(((EMA_5(volume) - EMA_20(volume)) / EMA_20(volume)) / 0.3)
```

进一步研究方向是统一成交金额口径和 20 / 60 日相对活跃度，形成 `trading_heat`。股、手、币等单位不能直接横向相加。缺失或无效成交量应为空值，不填成零。OI、流动性深度和基本面估值仍属于研究扩展。

综合热度应先做资产内归一化，再跨资产排序；分别展示价格方向、价格扰动、交易活跃和外部关注。高热度可能来自趋势扩散，也可能来自拥挤或恐慌。

## 文章观点

### 逐资产提取

保留文章中重点讨论的最多三个可交易资产，按资产分别记录看多、看空、中性或分歧，以及一句话依据。引用原文名称，只有映射明确时才填写规范身份。文章级总分不能代替逐资产立场。

旧 Prompt 规定：长期看好但短期担忧、不追高或降风险时，优先按当前可交易立场记为偏空。这是旧标签规则；“不买”与“值得做空”并不等价，策略判断必须另行处理。旧文档在资产选择上分别出现“观点强度优先”和“讨论篇幅优先”，迁移未替其选定新标准。

相关 Prompt 保留在 [观点抽取](../../resources/legacy/prompts/article_import_zh_cn.md)。未知标的应进入待研究列表，不根据名字猜资产类别。

### 方向与覆盖强度分开

早期文档中的文章到资产贡献为：

```text
s_i = article_base_score * time_decay * author_weight
      * concentration_penalty * edge_weight
time_decay = 2 ^ (-age_days / half_life_days)
direction_score = sum(s_i) / (sum(abs(s_i)) + eps)
coverage = sum(abs(s_i))
confidence_score = tanh(coverage / c)
total_score = direction_score * confidence_score
```

后续逐资产设计应使用该资产的观点分数，而不是把文章总方向复制给所有资产。没有有效贡献时，数学分数可定义为零，但报告必须区分“没有证据”和“多空抵消”。

`direction_score` 表示方向一致性；`confidence_score` 是覆盖强度的饱和变换，不是预测正确概率。重复转载、单一作者高频发文都可能放大表面证据，因此保留作者权重和集中度约束。旧配置默认作者权重为 1，集中度倍数为 3，并包含人工权重，均属于主观旧设定。

对 `abs(total_score)` 做 180 日历史分位数，可描述观点强度相对该资产自身的异常程度。该分位数不表达多空方向。

### 参数与版本分歧

| 项目 | 旧配置 | 文档中的其他设定 |
|---|---|---|
| 观点窗口 | 32 天 | 部分研究使用其他历史观察窗 |
| 观点衰减半衰期 | 7 天 | scoring v2 草案示例为 5 天 |
| 覆盖压缩常数 c | 2.0 | 有自适应研究，旧配置关闭 |
| 信号侧报告衰减 | 30 天 | 与文章聚合衰减属于不同层，不能互相替代 |

自适应 c 的研究目标是让近期尾部分数接近某目标值，但 `abs(total_score) <= abs(direction_score)`，方向不一致时无法靠调 c 保证目标。调强分数也不等于提高预测质量。

## 信号组合与策略表达

旧配置同时有顶层权重 `opinion=0.4, report=0.3, feature=0.3` 和信号参数 `feature_weight=0.3, report_weight=0.3`。本次原样保存两层参考，不把它们拼成一套未经核实的新公式。

通用因子可包括趋势、反转和波动；股票估值、期货期限结构、永续资金费率属于各自市场的专属信息。方向、覆盖和风险状态分别解释后，才讨论交易表达和预算。

| 策略 | 旧规则 | 保留的局限 |
|---|---|---|
| 精选做多 | 仅选正信号，降序取前 N；同分按代码排序；数量不足则少持有；策略内部等权 | 旧 N=10，不是新推荐值；缺少估值、流动性等过滤不能靠排名弥补 |
| 现货与永续配对 | N 对标的等额分配毛敞口，每条腿为正负 `1/(2N)` | 旧形态没有按资金费率、基差或价差 z-score 决定入场；不能据此声称有套利收益 |

旧预算为精选做多 0.7、配对 0.3；旧账户上限为总资产的 30%，单标上限为账户的 40%。保留这些规则的含义，不继承为当前仓位建议。配对要另外研究保证金、基差变化、资金费率反转、流动性和交易成本。
